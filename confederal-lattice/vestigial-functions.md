# Vestigial Functions — Consolidated Design

**Scope**: FRN-01, TEC-01, CUL-01, EMS-01. These are intentionally minimal — most functions collapse into existing structures or remain vestigial. Same universal principles apply (county unit, state = coordination + minimum standards (Art II §2.1), no federal agencies, LVT funding, sortition/recall, sunset, county veto + secession).

---

## 1. FRN-01: Foreign Relations

**Principle**: _Diplomacy is a county-to-county relationship. The Confederation has no foreign policy — only a mailbox._

| Element                       | Design                                                                                                            |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **Diplomatic Receipt Office** | ~12 staff (federal remnant). Accepts credentials, maintains treaty registry. No outgoing diplomacy.               |
| **Treaties**                  | No treaty binds without majority-of-counties ratification. Counties/states may form sister-region pacts directly. |
| **Trade agreements**          | County/compact level. No federal trade authority.                                                                 |
| **Extradition**               | Criminal Investigation Compact (law-enforcement.md). County judge → governor's warrant → sheriff transport.       |
| **Consular access**           | Foreign consulates permitted by county. No federal role.                                                          |
| **Recognition**               | No federal recognition power. Counties recognize whom they deal with.                                             |
| **War/peace**                 | Art III §4 chain (Congress + county referendum + state opt-in + county opt-in).                                   |

**Replaces**: State Dept, USAID, USTR, Ex-Im, DFC, intelligence community (foreign).

---

## 2. TEC-01: Technology & Communications

**Principle**: _Spectrum is a local commons. Networks are county utilities. No FCC, no NTIA._

| Element                | Design                                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| **Spectrum**           | County/compact auctions (<6 GHz); unlicensed commons (>6 GHz). See infrastructure.md §3.3. |
| **Fiber/mesh**         | County fiber utility (open access); Digital Backbone Compact. See infrastructure.md §3.    |
| **Satellite**          | County/compact negotiates directly with operators. No federal allocation.                  |
| **Digital ID**         | County Residency Credential (cryptographic). No federal ID.                                |
| **Encryption**         | Absolute. No backdoors. Compelled decryption = self-incrimination (Art VI §2.6).           |
| **AI governance**      | County validation (cyber unit + clinical/technical review). No federal AI agency.          |
| **Platform liability** | County law (fraud, defamation, antitrust). No Section 230.                                 |
| **Data privacy**       | County law (stricter than GDPR). No federal preemption.                                    |

**Replaces**: FCC, NTIA, FTC (tech), CISA (civilian), NIST (mandatory parts).

---

## 3. CUL-01: Culture, Media, Information

**Principle**: _Culture is voluntary association. Libraries and archives are county commons. No federal cultural policy._

| Element                 | Design                                                                                                |
| ----------------------- | ----------------------------------------------------------------------------------------------------- |
| **Libraries**           | County-funded (LVT). Open access. No federal IMLS.                                                    |
| **Archives**            | County records + state historical societies. No NARA (federal records go to counties on dissolution). |
| **Public broadcasting** | County/compact-funded (optional). No CPB.                                                             |
| **Misinformation**      | No government truth authority. County rights law (fraud, defamation) applies. Platforms = private.    |
| **Arts funding**        | County grants (competitive, sortition panel). No NEA/NEH.                                             |
| **Monuments/museums**   | County/private. No federal designation.                                                               |

**Replaces**: IMLS, NARA, NEA, NEH, CPB, Smithsonian (federal role).

---

## 4. EMS-01: Civil Emergency Management

**Principle**: _Emergencies are local. Mutual aid is voluntary. No FEMA, no federal emergency declaration._

| Element                      | Design                                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| **County EOC**               | County emergency management agency (LVT-funded). All-hazards planning.                           |
| **Mutual aid**               | Regional Emergency Compact (infrastructure.md §10). Typed resources, cost+10% reimbursement.     |
| **Pandemic**                 | County public health (healthcare.md §5). No federal CDC. No mandates.                            |
| **Grid collapse**            | County utility + Electric Reliability Compact. Microgrids for Tier 1 facilities.                 |
| **Asteroid/space weather**   | Compact coordination. No federal space agency (NASA → counties/private).                         |
| **Continuity of governance** | County charter specifies succession (commission chair → sheriff → clerk). No federal continuity. |
| **Strategic reserves**       | County/compact (fuel, medical, transformers, food). No federal stockpiles.                       |
| **Recovery**                 | County LVT + mutual aid. No federal disaster grants.                                             |

**Replaces**: FEMA, DHS (emergency), CDC (emergency), SNS, Strategic National Stockpile.

## Cross-Cutting Summary

| Subsystem  | Replaced Federal Entity        | New Home                                             |
| ---------- | ------------------------------ | ---------------------------------------------------- |
| **FRN-01** | State Dept, USAID, USTR, Ex-Im | Diplomatic Receipt Office (12 people) + county pacts |
| **TEC-01** | FCC, NTIA, CISA (civilian)     | County spectrum boards + Digital Backbone Compacts   |
| **CUL-01** | IMLS, NARA, NEA, NEH, CPB      | County libraries/archives + private culture          |
| **EMS-01** | FEMA, DHS, CDC (emergency)     | County EOCs + Regional Emergency Compacts            |

**All four share**: no federal agency, no federal funding, county administration, compact coordination, sortition/recall accountability, sunset review, county veto + secession backstops.

---

## Why These Are "Low Priority"

- **FRN-01**: Foreign relations shrink to near-zero when there's no federal military, no foreign aid, no intelligence community. A 12-person mailbox is sufficient.
- **TEC-01**: Most technology governance is already handled by infrastructure.md (spectrum, fiber) and civil-liberties.md (privacy, encryption). Only residual policy remains.
- **CUL-01**: Culture and media are private goods. Counties fund libraries/archives as commons; everything else is voluntary association.
- **EMS-01**: Emergency management is already distributed across infrastructure.md (mutual aid, reserves), healthcare.md (public health), and law-enforcement.md (cyber). Only the county EOC and continuity-of-governance pieces are new.

**None of these require a new institution beyond what already exists.** They are the "thin residue" after the federal state dissolves.
