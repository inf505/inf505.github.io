# The County-Confederal System — Master Index

A complete design for dismantling the U.S. federal state and replacing it with a county-based confederation. Written as a thought experiment: one dictatorial act, then vanish.

**Design version**: v1.1 (2026-11-03, through Change Set 11) — full history in `changelog.md`. Design freeze lifted; open for design changes (see `open-issues.md` for tracked work).

---

## What This Is

The starting point is `agorist-solutions.md`: 22 structural features of American politics that **neither major party will run on or seriously discuss** — the dollar's reserve role, the Fed, the surveillance state, corporate personhood, the prison system, occupational licensing, and so on — each with its county-level solution.

The design asks: _if a single actor could change any of it, what would a coherent replacement look like?_ The answer is **agorist/localist**: push authority down to the county (the smallest unit with real capacity), keep the state as a thin coordination + minimum-standards layer, and reduce the federal government to a vestigial shell (224 people).

The guiding logic:

- **Subsidiarity** — decisions at the lowest competent level.
- **Exit over voice** — counties can secede; residents can move; nothing is forced.
- **Voluntary coordination** — compacts, not mandates.
- **No permanent center** — the designer vanishes; no successor inherits power.

**Assumptions & constraints:**

- This assumes a _single dictatorial act_ to start. It is **not** a democratic transition plan.
- It is a _design_, not a forecast. Numbers are illustrative.
- It deliberately trades some efficiency for accountability and exit.
- It is internally consistent but not stress-tested against real scenarios (see Status).

## The System in One Page

| Layer                | Unit                             | Role                                                                                            | Funding                                                                                    |
| -------------------- | -------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **County** (all)     | Sovereign                        | Everything: taxes, courts, police, schools, health, land use, currency acceptance               | LVT + consumption tax + user fees                                                          |
| **State** (50)       | Coordination + minimum standards | Guard, appellate courts, compacts, land registry, SWF, minimum standards (5 domains)            | Capped county contributions (≤15% LVT) + infrastructure surcharge (participating counties) |
| **Compact** (varies) | Voluntary                        | Infrastructure, watersheds, grid, rail, cyber, mutual aid                                       | Per-mile/acre/strand assessments                                                           |
| **Confederation**    | Vestigial                        | War declaration, interstate commerce (narrow), coin minting, diplomacy receipt, nuclear council | Capped state assessments (<$60M/yr)                                                        |

**No executive branch. No federal police. No federal military. No central bank. No income tax. No federal agencies.**

## The Vanish Protocol (Summary)

1. **Decree** (Year 0): Dissolve the old order and promulgate the Constitution for ratification. Abolish executive, Fed, income tax, federal LE, military command, agencies. Sunset all statutes in 5 years. (Constitution is provisional until ratified by 2,000+ counties, target Year 2.)
2. **Stand-Up** (Years 1–2): Counties ratify charters. Mutuals chartered. Compacts formed. Sheriffs elected. Courts seated. State AG elected; minimum standards adopted; State Courts of Appeals seated.
3. **Cutover** (Years 3–4): Federal budget <$60M. State guards operational. Competitive currency normal. State appellate original jurisdiction active; interposition threshold (20 states) tested.
4. **Lock-In** (Year 5): All prior statutes void unless re-authorized. Charters re-ratified. State minimum standards re-adopted or lapse.
5. **Vanish**: Publish everything. Appoint county stewards by sortition (one per county). Dissolve federal executive. Walk away. **No successor. No center. No ruler.**

## Glossary

| Term                                    | Meaning                                                                                                                |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Agorism**                             | Libertarian strategy of building voluntary, non-state institutions; here, the localist bias of the design.             |
| **County**                              | The sovereign operating unit (all counties). Holds all residual powers.                                                |
| **Compact**                             | A voluntary, specific, terminable agreement among counties/states (e.g., watershed, grid, rail). Not a new government. |
| **County veto**                         | Majority of county commissions (>50% of population) can nullify any federal act anytime; state acts within 90 days.    |
| **Sortition**                           | Selecting officials/jurors by random lot (like jury duty) instead of election.                                         |
| **LVT (Land Value Tax)**                | Tax on _unimproved_ land value only; buildings/improvements untaxed. Primary county revenue.                           |
| **TAN (Tax Anticipation Note)**         | Short-term county note (≤180 days) accepted for local tax payment; circulates as local money.                          |
| **CRC (County Residency Credential)**   | Cryptographic ID issued by county clerk; replaces visa/green card; portable across counties.                           |
| **SBI (State Bureau of Investigation)** | State-level investigators for interstate crimes only (kidnapping, counterfeiting, piracy, treason, cross-state cyber). |
| **IDCO**                                | Interstate Defense Coordination Office — 12-person federal node for guard comms; no command authority.                 |
| **SWF (Sovereign Wealth Fund)**         | State fund from severance/land revenue; dividends flow to counties.                                                    |
| **Transition Trust**                    | 10-year vehicle that settles all legacy federal claims (debt, pensions, contracts); dissolves at Year 10.              |
| **Mutual**                              | Member-owned, non-profit county cooperative (health, pension, unemployment, disability). Not a government program.     |
| **Interposition**                       | 20+ state legislatures nullify a federal ruling/statute for their jurisdictions.                                       |
| **Backstops (escalating)**              | County veto → interposition → secession. Each is a check on central overreach.                                         |
